C++ CCA Programs

About the Project

This repository contains 20 C++ programs developed for CCA practicals and practice. The programs cover five important C++ concepts: Arrays, Enumerations (Enum), Structures, Pointers, and Unions.

Objectives

- Understand basic C++ programming concepts.
- Learn how to use arrays and access their elements.
- Understand enumerations and user-defined data types.
- Store and process data using structures.
- Learn pointer operations and memory addresses.
- Understand unions and shared memory.

Technologies Used

- Programming Language: C++
- Compiler: GCC/G++ (MinGW-w64)
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

How to Run the Programs

Prerequisites

1. Install Visual Studio Code.
2. Install the C/C++ extension by Microsoft.
3. Install MinGW-w64 with GCC/G++.
4. Configure the compiler in the system PATH.

Steps

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required ".cpp" file.
4. Open the terminal using Terminal → New Terminal.
5. Compile the program using:

g++ "filename.cpp" -o program.exe

6. Run the program on Windows using:

.\program.exe

Replace "filename.cpp" with the actual source filename. Keep quotation marks if the filename contains spaces.
